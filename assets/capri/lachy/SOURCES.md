# Artwork attribution

These 13 PNG animation strips are copied unchanged from
https://github.com/lachydotmcg/capri-desktop/tree/main/assets/sprites.

The original artwork and animation timing are credited to that project and its
respective contributors/rights holders. Capri and Cyberpunk: Edgerunners belong
to their respective owners. This private integration does not claim ownership
of the artwork or extend the companion's MIT code license to it.

The integration uses original cells directly, with reflection, small transforms,
the supplied mouth overlay, and the companion's existing teleport effects.
The three traced poses in the upstream companion remain in the source archive
but are not used to draw the visible character in this version.
