# Capri 0.3.1

Installs the personal-context prototype on top of the complete 0.3.0 release.

- Current whereabouts and current work are sourced, dated, superseded and
  connected to existing project identities. Returning to PC input does not
  establish an arrival, destination or outcome.
- Short intentions persist across restarts and become eligible after a matching
  delivered reply, a reported prerequisite completion or a stated time. One
  delivered callback ends further unsolicited follow-up. Changes of plan,
  dismissal, quiet/focus, sleep, privacy and direct conversation take priority.
- Due project follow-ups share the existing bounded behavior/model lane.
- Capri's own established tastes retain their actual supporting quotes and
  reasons. They remain distinct from user preferences.
- Working understanding in Memory exposes sources and completion, stop, forget
  and clear controls. Existing history/privacy/reset controls cover the new data.
- Targetless personal callbacks can survive a routine pose change while still
  yielding to actual placement, direct interaction, exchange and privacy changes.

The packaged Windows application passed 538 unit tests and all 26 selected
packaged checks, including personal context, native reply focus, dialogue panels,
movement/rest behavior, topic grounding and profile persistence. The installed
package matches all 149 checked files. The complete stopped profile and previous
0.3.0 package were backed up before replacement; all 94 checked profile files
were unchanged during replacement. Restart loaded 40 approved memories without
repairs, connected to Codex, and reached character-ready in 963 ms.

A local Honcho 3.4.1 comparison server was also set up separately from the app.
Real synthetic tests used the same underlying text model. Both systems answered
six ordinary recall questions correctly. With raw chat excerpts withheld, Honcho
retained preferences/reason and a class deadline missing from Capri's learned
profile in that run. This identifies profile consolidation as a useful next
integration target; it does not establish general superiority. The service is
not automatically syncing production Capri data. The comparison SDK adapter now
deletes its active synthetic session before deleting its workspace, matching the
actual server lifecycle.

The historical implementation report remains in `docs/personal-context`.
Its statement that the prototype is not installed describes the earlier stage;
the native features listed here are now installed as 0.3.1.
