Native movement receipts and current renderer pose remain authoritative. Direct generated replies are checked before text/audio delivery, including when no retired expressions exist; a blank cancellable response placeholder preserves interruption controls without exposing an unchecked draft.

Chat and bubbles distinguish authored line ID, generated direct reply, generated spontaneous remark, action result and system error. Retiring a line disables its exact authored ID. New generated feedback never creates a text blacklist. Earlier user-retired expressions are preserved through compatibility loading; old messages do not receive fabricated provenance. Generated feedback stores category/time only, at most 128 records for 30 days, with startup/hourly pruning through the existing heartbeat. Disabling history removes it. Private replies do not store feedback. Timing feedback pauses optional speech for ten minutes; other categories add temporary generation guidance. Permanent personal memory is not mutated.

DialogueCognition keeps attributed positions, reasons, corrections, answered/abandoned questions and explicit closure. Up to eight closed subjects expire after 24 hours; explicit user reopening releases a subject. The closure guard generalizes across subjects and suppresses an unnecessary callback while acknowledging criticism. It is a conservative lexical policy, not a semantic model or permanent generated-text blacklist. RelationshipStore remains the distinct owner of Capri opinions and project threads.
