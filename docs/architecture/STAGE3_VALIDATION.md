The installed Codex version is **0.165.0-alpha.1.2**. Its exported experimental
schema supports thread start/resume/fork/delete/compact and turn start/interrupt.
The adapter checks required methods and safe parameter shapes before inference.
A local synthetic Responses endpoint captured **zero model tools**, with empty
additional capability inventory. This audits the actual installed harness and
user configuration, rather than trusting the dialogue prompt alone.

The first 22-turn fictional Glass Finch sequence completed. It included a design
opinion, a warning-color correction, follow-ups, a pat, dinner, explicit topic
closure, an imagined outing, a poke, an App Server process restart before turn 13,
and native compaction followed by a successful reply. Persistent deletion was
followed by another process restart and a rejected resume of that exact ID.

Two further 22-turn sequences supplied the conversational-state projection. The
first exposed a false historical claim after compaction: Capri said she switched
from red to blue even though she originally favored teal. This is preserved.
The final sequence included the actual first/correction replies as authoritative
application excerpts at compaction recovery, matching the application's selective
retrieval contract. It recovered the actual pale-green recommendation and its
warning-contrast reason. Its word “switched” still overstates a change: the initial
recommendation was already pale green. This remains a generation weakness rather
than being rewritten out of the record.

Manual semantic review also flags the baseline pat's gratuitous warning-color
callback and the tendency to restate a preference while supposedly elaborating.
The final run changed to dinner/outing subjects and respected the color-closure
request, but occasionally sounded generic. No claim of perfect semantic repetition
suppression, perfect character performance or an automatic semantic quality score
is made. The small state model plus exact attributed retrieval materially support
continuity; they do not guarantee factual recall from a lossy native summary.

First attempts, weak replies, protocol failures and both cognitive runs remain in
the output JSONL records. The first probe failed because this protocol requires a

cached-input, output and elapsed values in those early records remain usable.
