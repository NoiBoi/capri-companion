# Deterministic two-day scenario

The accelerated scenario uses a virtual clock spanning 48 hours, real LifeContext, AgencyRuntime, DialogueCognition, PerformanceDirector and CognitiveSqlite. All nine supported source kinds are represented with realistic synthetic observations. Placement receipts are simulated. This establishes integrated state/control behavior, not two days of actual inbox, geofence, game, browser or CAD use. External account authorization was not requested.

The scenario executes 25 assertions, 2,280 minute ticks while active, seven synthetic native executions and zero model calls. Ten suspended hours advance wall time without a reasoning tick. The final SQLite file is 167,936 bytes. See the saved scenario-results.json for the ordered trace.

Academic work preserves unknown submission from browser/calendar evidence; the direct report becomes user-reported submission and closes callbacks across the recognized assignment and unambiguous matching page/calendar title. A current negative correction replaces the earlier user report. Similar project names use longest overlapping mentions; separate mentions may still identify both projects. Identical names remain ambiguous and must not grant an action target.

The half-hour quiet stay activates only with a verified synthetic negative-monitor position, survives restart with the absolute deadline, and completes without a model. Invalid placement and lost-window revalidation fail without an active stay. Explicit release/user override relinquishes movement. An expired overnight stay does not replay placement after resume.

CAD filenames establish project activity, never inspected geometry; repeated unchanged metadata does not revive a settled candidate. A gym geofence remains phone proximity with unknown activity. Leisure allows a specific remark; repeated video metadata stays settled. Gaming/call availability defers communication without consuming attention attempts. A matching email/meeting bundle becomes eligible afterward. Source revocation removes evidence, snapshots and retrieval. Out-of-order revisions are rejected. Private dialogue does not change persistent conversational state. Day two retains a sourced Capri opinion, current user correction and a meaningful changed-project opportunity.

Failures preserved: the first scenario attempt matched Glass Finch Lab Two to both project entities; the next attempt left cross-source homework callbacks pending after user submission. Both drove implementation changes and the entire scenario was rerun. No test expectation was relaxed to accept these bugs.

Cross-cutting checks outside the chronological scenario: native Electron placement/multi-monitor transition, source revocation across SQLite/native sessions, process restart, OAuth state/PKCE and credential expiry, network/quota backoff, private ephemeral sessions, model compaction and rotation, malformed/future data, SQLite interrupted transaction recovery and migration backups. Exact final counts and live verification results belong in FINAL_REPORT.md. An authorized live source test is distinct from a fixture adapter response and must never be inferred from these results.
