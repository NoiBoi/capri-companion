# Capri 1.1.2

Includes the previously uncommitted 1.1.1 interface and embodiment updates, followed by a focused movement correction.

## Movement

- Small window moves wait for release and settled geometry before one relocation, replacing continuous carrying.
- Blocked or covered perch destinations wait quietly instead of repeating teleport effects. Landing safety is checked before departure and during travel.
- Resizing a window without changing its perch position or pose does not trigger a teleport.
- Drop snapping chooses the nearest safe edge with a capture distance scaled to character size. A landing line previews an eligible perch during dragging.
- Pickup cancels older travel. High-window inverted perches, cursor visits, window tours, lower rests and sleep remain available.

## Included 1.1.1 updates

- Consistent controller, conversation and settings appearance; suggested settings search; a separate developer window with search and filtering.
- An opt-in capability switch that restores the preferences it changes when disabled.
- Distance-scaled flight with gradual acceleration and braking, travel facing and landing settlement.
- Reply activation and focus-restoration improvements, draft preservation and input-method handling.

## Validation

- Type checking passed.
- 31 targeted unit checks passed.
- Seven focused packaged movement checks passed, including native Windows geometry, blocked landing recovery, drag/release, interrupted flight, sleep, character focus and preference preservation.
- All 67 packaged build files matched the production build; no private profile files were included.

The full historical suites and every monitor/DPI combination were not rerun for this movement pass. Native composer keyboard-focus tests were not run. The existing source launch remains supported; this pass validated an unpacked package without creating a new installer.
